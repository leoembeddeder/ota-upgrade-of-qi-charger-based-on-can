## 1. 基本下载流程

- [X] **TC-0101** (P0) — 完整 APP 内下载流程
  - 前置: APP 正常运行，CAN 链路正常
  - 步骤: `10 02`→`27 01`→`27 03`(16帧)→`27 02`→`2E 2010 01`→`31 01 FF 00`→`34`→`36`循环→`37`→`11 01`
  - 预期: 全流程正响应，MCU 复位后 BOOT 搬运 Backup→App

- [X] **TC-0102** (P0) — 已有备份区镜像时升级
  - 前置: 设备已完成至少一次 OTA（备份区已有镜像）
  - 步骤: 安全解锁→`2E 2010 01`→擦备份区→`34`→`36`→`37`→`11 01`
  - 预期: 升级成功，BOOT 搬运后新版本生效

- [X] **TC-0103** (P0) — 不同大小镜像下载
  - 前置: 有效镜像已准备（pack_image.py 打包）
  - 步骤: 分别用最小/正常(~30KB)/最大(接近48KB)镜像执行完整下载
  - 预期: 三种大小均下载成功

- [X] **TC-0104** (P1) — TesterPresent 保活
  - 前置: APP 编程会话已建立
  - 步骤: 执行下载流程，关键步骤间插入 `3E 80`
  - 预期: 全流程无 S3 超时

- [X] **TC-0105** (P1) — ResponsePending 时序
  - 前置: APP 编程会话
  - 步骤: 观察擦备份区(`31 01 FF 00`)和验签(`37`)的响应时序
  - 预期: 先收到 `7F xx 78`，等待后收到正响应

- [X] **TC-0106** (P2) — SN 保留验证
  - 前置: SN 已写入，OTA 升级完成
  - 步骤: OTA 升级 → 复位后读 DID `F18C`(SN) 和 `F195`(SW 版本)
  - 预期: SN 与 OTA 前一致，SW 版本为新版本

## 2. Qi 充电 DID

- [ ] **TC-1001** (P0) — 读取充电器能力
  - 前置: APP 正常运行
  - 步骤: `22 21 00`
  - 预期: 返回 4 字节，byte0=0x0F（15W）

- [X] **TC-1002** (P0) — 写入充电器使能
  - 前置: APP 正常运行
  - 步骤: `2E 21 01 01`→`22 21 02`
  - 预期: `6E 21 01` 正响应；PA0 检测到手机时 PB2 拉高

- [X] **TC-1003** (P0) — 读取充电状态
  - 前置: 充电器已使能，手机已放置
  - 步骤: `22 21 02`
  - 预期: 返回 CHARGING(0x04)

- [ ] **TC-1004** (P0) — 写入功率限值
  - 前置: APP 正常运行
  - 步骤: `2E 21 0D E8 03`(1000mW)→`22 21 0D` 读回
  - 预期: 写入成功，NVM 持久化

- [ ] **TC-1005** (P1) — 读取设备在位状态
  - 前置: APP 正常运行
  - 步骤: `22 21 03`
  - 预期: 返回 0x01（在位）或 0x00（不在位）

- [ ] **TC-1006** (P1) — 读取夹臂状态
  - 前置: APP 正常运行
  - 步骤: `22 21 18`
  - 预期: PA0 低=0x00（有手机），高=0x01（无手机）

- [ ] **TC-1007** (P1) — 读取故障码
  - 前置: APP 正常运行
  - 步骤: `22 21 0B`
  - 预期: 返回 0x00（无故障）或对应故障码

- [ ] **TC-1008** (P1) — 读取 FOD 状态
  - 前置: APP 正常运行
  - 步骤: `22 21 09`
  - 预期: 返回 0x00（正常）或 0x02（FOD 确认）

- [ ] **TC-1009** (P2) — 功率限值 NVM 持久化
  - 前置: APP 正常运行
  - 步骤: 写 0x210D=1500→复位→读 0x210D
  - 预期: 复位后仍为 1500 mW

- [ ] **TC-1010** (P2) — Qi IAP 状态读取
  - 前置: APP 正常运行
  - 步骤: `22 21 32`
  - 预期: state=0x00（空闲），progress=0x00

- [ ] **TC-1011** (P2) — Qi 芯片版本读取
  - 前置: Qi 芯片已发过 UART `0x01` 上报
  - 步骤: `22 21 33`
  - 预期: 2 字节 uint16 LE 版本；未上报时 `00 00`

## DID 速查

| DID | 含义 |
|---|---|
| `0xF195` | 运行固件版本（OTA 升级判定依据） |
| `0x2113` | 运行区标识（单 App 架构恒 `0x00`） |
| `0x2114` | OTA 目标标记：`0x02`=备份区有镜像，`0xFE`=无 |
| `0x2115` | last_boot_reason |
| `0x2116` | 搬运重试计数 |
