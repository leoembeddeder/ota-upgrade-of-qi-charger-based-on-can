# 宏定义切换方式

> 项目中所有可通过宏定义切换的行为模式汇总
> 更新：2026-09-02

---

## 使用方法

在 Keil `.uvprojx` → **C/C++** → **Define** 中添加宏，多个用逗号分隔：

```
BOOT_JUMP_METHOD=1,SAFE_MODE_PROBE_ENABLE=1
```

或在源文件顶部 `#define`（仅对该文件生效）。

---

## 1. BOOT_JUMP_METHOD

| 项目 | 说明 |
|------|------|
| 文件 | `qi_wireless_bootloader/mdk_app/Src/boot_jump.c` |
| 默认值 | `0` |
| 取值 | `0` 或 `1` |

| 值 | 方式 | 说明 |
|----|------|------|
| `0` | 内联汇编 | `msr msp` + `bx`，编译器无关，当前默认方式 |
| `1` | 函数指针 | `__set_MSP` + `((app_entry_t)(reset_addr))()`，官方 IAP 风格 |

**代码位置**：
```c
#ifndef BOOT_JUMP_METHOD
#define BOOT_JUMP_METHOD  0
#endif
```

**切换方式**：Keil Define 中加 `BOOT_JUMP_METHOD=1`，或改默认值为 `1`。

**差异说明**：
- 方式 0：`msp` 和 `reset` 通过内联汇编寄存器传入，跳转后不依赖 C 栈，更安全
- 方式 1：先调 `__set_MSP` 再通过函数指针跳转，与官方例程一致，可读性更好

---

## 2. SAFE_MODE_PROBE_ENABLE

| 项目 | 说明 |
|------|------|
| 文件 | `qi_wireless_bootloader/mdk_app/Src/boot_safe_mode.c` |
| 默认值 | `0`（禁用） |
| 取值 | `0` 或 `1` |

| 值 | 说明 |
|----|------|
| `0` | Safe Mode 不主动发送周期 CAN 帧 |
| `1` | Safe Mode 每 500ms 发送一帧 `0x18FF260D`（byte[0]=0x00），用于总线监听确认 MCU 存活 |

**代码位置**：
```c
#define SAFE_MODE_PROBE_ENABLE     0U
#define SAFE_MODE_PROBE_PERIOD_MS  500U
#define SAFE_MODE_PROBE_STATE      0x00U
```

**用途**：调试时开启，确认 Bootloader 是否进入了 Safe Mode。生产环境关闭以减少总线负载。

---

## 3. SAFE_MODE_SIT1145_KEEPALIVE_ENABLE

| 项目 | 说明 |
|------|------|
| 文件 | `qi_wireless_bootloader/mdk_app/Src/boot_safe_mode.c` |
| 默认值 | `1`（启用） |
| 取值 | `0` 或 `1` |

| 值 | 说明 |
|----|------|
| `0` | Safe Mode 不主动刷新 SIT1145 Normal 模式 |
| `1` | Safe Mode 主循环每 500ms 调用 `sit1145_normal_mode_set()`，防止收发器掉入 Standby |

**代码位置**：
```c
#define SAFE_MODE_SIT1145_KEEPALIVE_ENABLE     1U
#define SAFE_MODE_SIT1145_KEEPALIVE_PERIOD_MS  500U
```

**建议**：保持为 `1`。Flash 写操作期间 CPU 停滞，SIT1145 可能因 SPI 无响应掉入 Standby。开启 keepalive 可在 Flash 操作后恢复 Normal 模式。

## 4. ENTRY_MODE（脚本侧）

| 项目 | 说明 |
|------|------|
| 文件 | `python_tools/zcanpro_ext_ota_from_app_slotA_1_1_1.py / zcanpro_ext_ota_from_boot_slotA_1_1_1.py / zcanpro_ext_ota_auto.py` 等 |
| 默认值 | `"auto"` |
| 取值 | `"auto"` / `"app"` / `"boot"` |

| 值 | 说明 |
|----|------|
| `"auto"` | 自动探测：发 `0x34`，若 NRC `0x11` 视为已在 APP，执行 `10 02` + `27` + `11 01` 进 Boot；否则视为已在 Safe Mode 直接下载 |
| `"app"` | 脚本先尝试让 APP 进 Boot（发 `10 02` + `27` + `11 01`），再进 Programming |
| `"boot"` | 脚本直接假设 MCU 已在 Boot Safe Mode，跳过 APP→Boot 步骤 |

**代码位置**：
```python
ENTRY_MODE = "auto"
```

**用途**：`"boot"` 用于 MCU 已在 Safe Mode 时直接 OTA（跳过等待）。`"app"` 用于正常从 APP 触发升级。`"auto"` 兼容两种场景。

## 5. TRANSFER_BLOCK_DATA（脚本侧）

| 项目 | 说明 |
|------|------|
| 文件 | `python_tools/zcanpro_ext_ota_from_app_slotA_1_1_1.py / zcanpro_ext_ota_from_boot_slotA_1_1_1.py / zcanpro_ext_ota_auto.py` 等 |
| 默认值 | `128` |
| 取值 | `1` ~ `254` |

| 值 | 说明 |
|----|------|
| `128` | 每帧传输 128 字节（默认，平衡速度与可靠性） |
| `254` | 最大值，每帧传最多数据（ISO-TP SF 上限） |
| `64` | 更保守，每帧更少数据 |

**代码位置**：
```python
TRANSFER_BLOCK_DATA = 128
```

**注意**：Bootloader 的 `UDS_MAX_BLOCK_LEN` = 256，`TRANSFER_BLOCK_DATA` 不应超过 `256 - 2`（SID + BSC）= 254。

## 6. IMAGE_MAGIC / IMAGE_HEADER_SIZE（镜像格式）

| 项目 | 说明 |
|------|------|
| 文件 | `python_tools/zcanpro_ext_ota_from_app_slotA_1_1_1.py / zcanpro_ext_ota_from_boot_slotA_1_1_1.py / zcanpro_ext_ota_auto.py` 等 + Boot `boot_metadata.h` |
| IMAGE_MAGIC | `0x4F544158`（"XATO"） |
| IMAGE_HEADER_SIZE | `256` 字节 |

这两个值在脚本和 Boot 两侧必须一致。修改需同步更新：

| 文件 | 用途 |
|------|------|
| `python_tools/zcanpro_ext_ota_from_app_slotA_1_1_1.py / zcanpro_ext_ota_from_boot_slotA_1_1_1.py / zcanpro_ext_ota_auto.py` 等 | `IMAGE_MAGIC`, `IMAGE_HEADER_SIZE` |
| `qi_wireless_bootloader/mdk_app/Inc/boot_metadata.h` | `IMAGE_HEADER_SIZE` |
| `qi_wireless_bootloader/mdk_app/Inc/boot_verify.h` | `IMAGE_MAGIC`（`ECDSA_PUBKEY_MAGIC`） |

## 7. 宏切换速查表

| 宏名 | 文件 | 默认值 | 取值 | 说明 |
|------|------|--------|------|------|
| `BOOT_JUMP_METHOD` | boot_jump.c | `0` | 0/1 | 跳转 APP 方式：0=汇编，1=函数指针 |
| `SAFE_MODE_PROBE_ENABLE` | boot_safe_mode.c | `0` | 0/1 | Safe Mode 周期探针帧 |
| `SAFE_MODE_SIT1145_KEEPALIVE_ENABLE` | boot_safe_mode.c | `1` | 0/1 | Safe Mode SIT1145 保持 Normal |
| `ENTRY_MODE` | zcanpro_ext_ota_from_app_slotA_1_1_1.py | `"auto"` | auto/app/boot | 脚本进入方式：auto=探测，app=先跳 Boot，boot=已在 Safe Mode |
| `TRANSFER_BLOCK_DATA` | zcanpro_ext_ota_from_app_slotA_1_1_1.py | `128` | 1~254 | 每帧传输字节数 |

## 8. Keil 工程配置示例

在 `.uvprojx` 的 **C/C++** → **Define** 中：

```
BOOT_JUMP_METHOD=1,SAFE_MODE_PROBE_ENABLE=1
```

效果：
- Bootloader 跳 APP 使用函数指针方式（官方 IAP 风格）
- Safe Mode 开启周期探针帧（调试用）

生产环境建议：
```
BOOT_JUMP_METHOD=0
```

效果：
- 使用内联汇编跳转（更安全）
- Safe Mode 不发探针帧（减少总线负载）
- SIT1145 keepalive 保持开启（默认）
