# APP 镜像打包与产线烧录

> **架构**：Boot + App + 备份区（OTA-ARCH-0920）。App 镜像固定链接
> `0x08004100`（Keil IROM1），无槽选择、无重定位。
> **适用**：Keil 编出 App 裸 `.bin` → `pack_image.py` 加 XATO 头 →
> `merge_prod_bin.py` 合并 Boot → 产线烧录；SN 由扫码 + CCU UDS 写入。

## 1. 工具与产物

| 工具 | 作用 | 位置 |
|---|---|---|
| `pack_image.py` | App 裸 bin → XATO 签名镜像，输出 `app bin/app_image.bin` | `python_tools/1.packaging script/` |
| `verify_image.py` | 校验 XATO 镜像（magic/length/CRC/Reset 窗口/ECDSA） | 同上 |
| `merge_prod_bin.py` | Bootloader + App 镜像 → `burn bin/prod_image.bin` | 同上 |

产线烧录内容 = **Bootloader + App 区镜像**（合并单文件）。备份区出厂为空（0xFF），留给 CAN OTA；metadata 出厂为空，BOOT 首启 defaults 自愈。

## 2. 烧录布局（merge_prod_bin.py 输出）

```
0x08000000  Bootloader (16KB 补 0xFF, 来自 bootloader Objects/bootloader.bin)
0x08004000  App 区：XATO 头 256B + 固件（≤48KB）
0x08010000  备份区：出厂不烧（0xFF）
0x0801C000  Metadata：出厂不烧（BOOT 首启 defaults）
```

## 3. 构建与打包步骤

1. Keil 打开 `qi_wireless_code_app/mdk_project/qi_wireless_code_app.uvprojx`
   （Target IROM1=`0x08004100`，Size=`0xBF00`）→ Rebuild →
   `Objects/qi_wireless_code_app.bin`。
2. `python pack_image.py`（默认输入即上述 bin；`--bin` 可指定路径，
   `--key docs/keys/private.pem`）→ 输出 `app bin/app_image.bin`。
   脚本自动校验：Reset 向量必须落 App 窗口 `[0x08004100,0x08010000)`，
   头 CRC 与 payload 一致，签名后 `_selfcheck_image` 独立仿射验签。
3. `python verify_image.py ../app\ bin/app_image.bin --key ../docs/keys/public.pem`
   → RESULT: PASS 后方可交付。
4. 产线：`python merge_prod_bin.py`（默认 boot+app_image.bin）→
   `burn bin/prod_image.bin` → 烧录器基址 `0x08000000`。

## 4. OTA 侧衔接

OTA 脚本 `zcanpro_ext_ota_auto.py` 将同一 `app_image.bin`（或 Keil 新 bin
现场打包）经 UDS 写入**备份区 0x08010000**：`31` 擦备份区 → `0x34`
（地址门禁=0x08010000）→ `0x36` → `0x37` 验签提交 → 设备自复位 →
BOOT 搬运 Backup→App（擦 App 区→复制→复核→清标志）→ 跳转 `0x08004100`
→ 主机复位后核验 `0xF195`==预期版本。

## 5. 常见问题

| 现象 | 原因 | 处置 |
|---|---|---|
| pack 报 Reset 不在 App 窗口 | Keil IROM1 不是 0x08004100 | 改 Target IROM1 后 Rebuild 再打包 |
| pack 报"skip (not found)" | Keil 输出名/路径不符 | 确认 `Objects/qi_wireless_code_app.bin` 存在或 `--bin` 指定 |
| OTA 后版本未变 | 备份区校验失败或搬运未完成 | 抓 M1~M4 诊断帧（zcanpro_boot_diag_capture.py）看 M2 搬运结果与 M3 验签关卡 |
| 合并 bin 报 App 过大 | 镜像超 48KB (0xC000) | 精简固件或检查打包输入是否为错文件 |
