# Flash 空间分配 — QI Wireless Bootloader

> **架构**：Boot + App + 备份区 单 App 升级流
> **MCU**: AT32F426 (Cortex-M4F, 128KB Flash, 20KB SRAM)
> **Flash 基地址**: `0x08000000` | **总大小**: 128KB (`0x08000000`~`0x0801FFFF`)

---

## 一、Flash 布局总览

| 区域 | 起始 | 结束 | 大小 | 扇区(4KB) | 说明 |
|---|---|---|---|---|---|
| Bootloader | `0x08000000` | `0x08003FFF` | 16KB (0x4000) | 0~3 | 引导程序：metadata 读取、备份区搬运、验签、跳转 |
| App 区（Application） | `0x08004000` | `0x0800FFFF` | 48KB (0xC000) | 4~15 | 应用固件运行区；XATO 头 @0x08004000，入口 0x08004100 |
| Backup（备份区） | `0x08010000` | `0x0801BFFF` | 48KB (0xC000) | 16~43 | OTA 暂存区：主机写入待升级固件，BOOT 校验后搬运至 App 区 |
| Metadata Primary | `0x0801C000` | `0x0801C7FF` | 2KB | 44~45 | OTA 元数据主副本 |
| Metadata Backup | `0x0801C800` | `0x0801CFFF` | 2KB | 46~47 | OTA 元数据备副本 |
| Device Info | `0x0801D000` | `0x0801DFFF` | 4KB | 48~51 | SN、ECDSA 公钥等设备标识；OTA 擦写永不触碰 |
| NVM Config | `0x0801E000` | `0x0801FFFF` | 8KB | 52~55 | APP NVM 配置区 |

```
0x08000000 ┌──────────────────────────────┐
           │     Bootloader (16KB)        │
0x08004000 ├──────────────────────────────┤
           │     App 区 (48KB)            │
0x08010000 ├──────────────────────────────┤
           │     备份区 (48KB)            │
0x0801C000 ├──────────────────────────────┤
           │  Metadata Primary (2KB)      │
0x0801C800 ├──────────────────────────────┤
           │  Metadata Backup  (2KB)      │
0x0801D000 ├──────────────────────────────┤
           │  Device Info (4KB)           │
0x0801E000 ├──────────────────────────────┤
           │  NVM Config (8KB)            │
0x0801FFFF └──────────────────────────────┘
```

各区边界相接零重叠。扇区 N 起址 = 0x08000000 + N×0x1000。

## 二、升级流程

### 2.1 主机侧

主机脚本（zcanpro_ext_ota_auto.py）按序执行：

`10 02` 编程会话 → `27` 安全解锁 → `31` 擦备份区（0x08010000~0x0801BFFF）→ `0x34`（地址门禁：仅接受 0x08010000）→ `0x36` 流式写入 XATO 镜像 → `0x37`。

### 2.2 APP 侧（ota_download.c）

flush → 长度核对 → verify_backup_image（magic/length/CRC32/ECDSA + Reset 向量必须落在 App 窗口 [0x08004100,0x08010000)）→ commit_backup（metadata：`backup_valid=1` + `backup_crc32`，先备后主双副本落盘）→ 0x77 正响应 → NVIC_SystemReset。

**APP 从不擦写自身所在的 App 区。**

### 2.3 BOOT 侧（boot_trial.c）

上电读 metadata → `backup_valid=1` → 重验备份区镜像 → 擦 App 区 → 字搬运 + 读回复核 → App 区再验签 → **复核通过才清标志**（app_valid=1、backup_valid=0 落盘）→ 跳转 `0x08004100`。

### 2.4 断电恢复

标志仅在搬运复核通过后清除；擦/搬/复核任一点断电，下次上电整链重跑（备份区为搬运源，不受搬运影响）。copy 失败时 fail_step 记入 metadata reserved_trial[0]、copy_retry_count++，旧 App 若仍可验签则照常启动。

## 三、ota_metadata_t 数据结构

v2 及以前 metadata 校验拒绝 → defaults 重建。

| 偏移 | 字段 | 大小 | 说明 |
|---|---|---|---|
| 0x00 | magic | 4B | 0x4F54414D "MATO" |
| 0x04 | version | 4B | 3 |
| 0x08 | app_valid | 1B | App 区镜像有效 |
| 0x09 | backup_valid | 1B | 备份区待搬运标志 |
| 0x0A | copy_fail_step | 1B | 上次搬运失败关卡 |
| 0x0B | last_boot_reason | 1B | 00=POR 01=SW 02=WDG 03=OTA 04=copy失败 |
| 0x0C | backup_crc32 | 4B | 备份区 payload CRC（搬运前比对值） |
| 0x10 | copy_retry_count | 4B | 搬运失败次数 |
| 0x14 | ota_state | 1B | 00=idle 01=downloading |
| 0x15 | reserved[3] | 3B | — |
| 0x18 | crc32 | 4B | 以上字段 CRC32 |

合计 0x1C = 28B。

定义源：boot_metadata.h 与 ota_trigger.h 逐字节同构。

## 四、XATO 镜像头

| 偏移 | 字段 | 大小 | 说明 |
|---|---|---|---|
| 0x00 | magic | 4B | 0x4F544158 "XATO" |
| 0x04 | image_length | 4B | 头之后固件字节数 |
| 0x08 | crc32 | 4B | payload CRC32 |
| 0x0C | signature[64] | 64B | ECDSA P-256 R\|\|S |
| 0x4C | hdr_reserved_ver[16] | 16B | 保留占位，打包填 0x00 |
| 0x5C | build_timestamp | 4B | Unix 时间戳 |
| 0x60 | reserved[160] | 160B | 补齐 256B |

版本号唯一真相源 = 固件 SW_VERSION_STR（can_protocol.c），DID 0xF195 直读。

## 五、产线烧录

`merge_prod_bin.py`：Bootloader（16KB 补 0xFF）+ App 镜像（XATO，≤48KB）→ `burn bin/prod_image.bin`，烧录基址 `0x08000000`。备份区与 metadata 出厂留 0xFF；首启 defaults 自愈，无需产线预写 metadata。

## 六、诊断帧

ID=0x18FF480D（扩展帧 DLC=8，`[0xA1~0xA4][数据...][0xCC 填充]`）：

- M1 = [app_valid][meta_src][magic][ver][crc]
- M2 = [搬运结果][detail]
- M3 = [pass][fail_step][目标区 0=Backup/1=App]
- M4 = [跳转地址 LE 4B]

抓取工具：`python_tools/zcanpro_boot_diag_capture.py`（通信层 v2）。

## 七、设计约束

| # | 约束 | 说明 |
|---|---|---|
| 1 | 地址对齐与擦除粒度 | 各区边界均按 4KB 扇区对齐；UDS `31` 擦除仅作用于备份区 |
| 2 | 地址门禁 | `0x34` 仅接受 0x08010000；APP 从不擦写自身所在的 App 区，App 区写入只发生在 BOOT 搬运路径 |
| 3 | ECDSA 验签时机 | 两处必验：① APP 侧 verify_backup_image；② BOOT 侧搬运完成后对 App 区再验签，复核通过才清标志 |
| 4 | metadata 双副本写入顺序 | 先写备副本，后写主副本；断电时选有效副本或 defaults 重建 |
| 5 | 标志清除时机 | backup_valid 仅在搬运复核通过后与 app_valid=1 同批落盘；断电时下次上电整链重跑 |
| 6 | Device Info 区保护 | OTA 擦写永不触碰 |
| 7 | Reset 向量约束 | Reset 向量必须落在 [0x08004100, 0x08010000) |
| 8 | 镜像容量上限 | XATO 镜像（256B 头 + payload）≤ 48KB |
| 9 | metadata 版本兼容 | META_VERSION=3；v2 及以前拒绝 → defaults 重建 |
