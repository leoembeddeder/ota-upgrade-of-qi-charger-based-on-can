# Python 脚本使用说明

> **架构**：Boot + App + 备份区单 App 升级流（OTA-ARCH-0920）。
> App 镜像固定链接 `0x08004100`；OTA 写备份区 `0x08010000`，BOOT 搬运至
> App 区 `0x08004000`；A/B 槽、重定位、目标槽选择均已取消。

## 脚本一览

| 脚本 | 作用 | 位置 |
|---|---|---|
| `pack_image.py` | App 裸 bin → XATO 签名镜像（`app bin/app_image.bin`） | 1.packaging script/ |
| `verify_image.py` | 校验 XATO 镜像（magic/length/CRC/Reset 窗口/ECDSA） | 1.packaging script/ |
| `merge_prod_bin.py` | Bootloader + App 镜像 → 产线合并 bin | 1.packaging script/ |
| `zcanpro_ext_ota_auto.py` | CAN-UDS OTA 升级主脚本（单 App 流） | python_tools/ |
| `zcanpro_boot_diag_capture.py` | Boot 开机决策链诊断帧抓取（M1~M4） | python_tools/ |
| `2.functional test script/` | 功能测试脚本（读版本/写 SN/充放电等） | python_tools/ |

## 分区常量（三方同源）

| 常量 | 值 | 说明 |
|---|---|---|
| Boot | `0x08000000`，16KB | 沿用 Keil IROM 实测 |
| App 区 | `0x08004000`，48KB（入口 `0x08004100`） | 运行区；Keil IROM1=`0x08004100,0xBF00` |
| 备份区 | `0x08010000`，48KB | OTA 暂存；`0x34` 地址门禁仅收此址 |
| Metadata | `0x0801C000`/`0x0801C800` | 28B×2 双副本，META_VERSION=3（v2 及以前拒收→defaults 重建） |
| XATO 头 | 256B，magic=`0x4F544158` | 0x4C 保留占位填 0x00 |

## pack_image.py

```bash
python pack_image.py                    # 默认: qi_wireless_code_app Objects/qi_wireless_code_app.bin
python pack_image.py --bin <path>       # 指定裸 bin
```
输出 `app bin/app_image.bin`；打包后自动 `_selfcheck_image`（Reset 窗口
[0x08004100,0x08010000) + CRC + 独立仿射验签，FAIL 拒绝产出）。

## verify_image.py

```bash
python verify_image.py "app bin/app_image.bin" --key ../docs/keys/public.pem
```
校验项：XATO magic / image_length ≤ 0xBF00 / CRC32 / Reset∈App 窗口 /
可选 ECDSA（openssl）。RESULT: PASS 方可交付。

## merge_prod_bin.py

```bash
python merge_prod_bin.py                # 默认 bootloader.bin + app_image.bin
python merge_prod_bin.py --hex          # 附带 Intel HEX
```
布局：Boot(16KB 补 FF)+App 镜像@0x08004000；备份区/metadata 出厂留 FF
（BOOT 首启 defaults 自愈）。烧录基址 `0x08000000`。

## zcanpro_ext_ota_auto.py（OTA 升级主脚本）

**流程**：选载荷（版本匹配优先/mtime 次序；`EXPECTED_SW_VERSION` 固化
`QC_JYF_FW_1.1.2`，不符 fail-closed 拒闪）→ 现场打包/校验 → 探测设备 →
基线确认（0x2113 信息展示 + 0xF195 版本）→ `10 02`→`27`→`31` 擦备份区
→ `0x34`@0x08010000 → `0x36` → `0x37`（设备验签提交后自复位）→ BOOT
搬运 → 复位后判定闭环（APP 应答 + 0xF195==EXPECTED；失败给差异明细）。

**判定口径（DID 判读表，取值以 C 码为源）**：单 App 架构下 `0x2113`
恒答 `0x00`（App 区运行），仅信息展示；成功判据 = 复位后 APP 应答 +
`0xF195`==预期版本。

| DID | 语义 | 取值与依据（file:line） |
|---|---|---|
| 0x2113 | 运行区标识 | 恒 `0x00`=App 区（ota_running_slot() deprecated shim 恒 0，ota_trigger.c） |
| 0x2114 | OTA 目标标记 | 下载中 `0x02`=备份区，否则 `0xFE`（can_protocol.c:725） |
| 0x2115 | last_boot_reason | `00`=POR `01`=SW `02`=WDG `03`=OTA 搬运 `04`=copy 失败（boot_metadata.h:58-62 BOOT_REASON_*；ota_trigger.h:60-65 OTA_BOOT_REASON_* 同值镜像；应答直读该字段 can_protocol.c:733） |
| 0x2116 | copy_retry_count | 搬运失败计数低 8 位（can_protocol.c:741） |

**v2→v3 metadata 重建（预期行为）**：设备旧 v2 元数据在刷入 Q2 瘦身固件
（META_VERSION=3）后被 Boot/APP meta_validate 判 version 不符→拒收→
defaults 重建（boot_metadata.c:104 / ota_trigger.c:31）；历史字段归零。
取证改依 CAN 诊断帧（M1~M4）+ metadata copy_fail_step/last_boot_reason。

**搬运断电恢复（幂等链）**：backup_valid 仅在搬运复核通过后清除
（boot_trial.c boot_copy_backup）；标志未清时断电→下轮上电整链重试
（先验后擦→搬运→App 区复核→清标志），任意环节断电均幂等；备份区为
搬运源不受影响，坏镜像在"先验"步被拒、不触发擦除。

**版本口径现状（升级前必读）**：固件 SW_VERSION_STR 唯一真相源当前=
`QC_JYF_FW_1.1.1`（can_protocol.c:53），升级脚本 EXPECTED_SW_VERSION=
`QC_JYF_FW_1.1.2`（zcanpro_ext_ota_auto.py:51）；发布版本升级前须把
SW_VERSION_STR 改为发布版本后 Keil Rebuild，否则拒闪门按设计 fail-closed
拦截（无版本匹配载荷）。

**运行**：ZCANPRO → 高级功能 → 扩展脚本 → 打开本脚本；前置 CAN 通道
250kbps 扩展帧；版本预期变更时改脚本头部 `EXPECTED_SW_VERSION` 常量。

## zcanpro_boot_diag_capture.py（Boot 诊断抓帧）

抓取 Boot 开机决策链 CAN 标记帧（ID=`0x18FF480D`，通信层 v2=照抄版本
工具/升级脚本真机验证模式）：
- M1 `[app_valid][meta_src][magic][ver][crc]` — metadata 读取现场
- M2 `[搬运结果][detail]` — 0=序列开始/无待搬运(0xFF)，1=提交成功，
  0xFF=失败（detail=fail_step，flag 保留下轮重试）
- M3 `[pass][fail_step][目标区 0=Backup/1=App]` — 验签现场（fail_step
  0xFF=验签开始标记）
- M4 `[跳转地址 LE 4B]` — 0x08004100=App 区

窗口内打印全部原始帧+总线活动统计；零帧二分（总线死 vs 有流量无诊断
帧）+降级兜底（UDS 通/raw 不通）。运行机需先 `git pull` 至最新。

## 常量一致性维护

分区常量改动必须三方同步：C 侧 `boot_metadata.h`（Boot）/`ota_trigger.h`
（APP）+ Python 侧 `zcanpro_ext_ota_auto.py`/`verify_image.py`/
`merge_prod_bin.py`；改后跑 `grep` 对照 + 全脚本 `py_compile`。
