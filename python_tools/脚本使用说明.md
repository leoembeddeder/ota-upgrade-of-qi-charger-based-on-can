# python_tools — 脚本使用说明

> **Python**: ZCANPRO 要求 **Python 3.8 32 位**
> **入口**: ZCANPRO → 高级功能 → 扩展脚本
> **总线**: Classical CAN 2.0B，250 kbps，29-bit 扩展帧

---

## 脚本总览

| 脚本 | 功能 | 位置 |
|------|------|------|
| `pack_image_slotA_1_1_1.py` | Slot A 裸 bin → 签名镜像（写入 B 时 OTA 脚本会重定位） | 1.packaging script/ |
| `merge_prod_bin.py` | Bootloader + Slot A 合并为产线镜像 | 1.packaging script/ |
| `verify_image.py` | XATO 镜像完整性 + 签名校验 | 1.packaging script/ |
| `sign_seed.py` | SecurityAccess seed 签名 | 1.packaging script/ |
| `zcanpro_ext_ota_auto.py` | **唯一 OTA 脚本**：APP 内写对面槽，必要时重定位 | 根目录 |
| `zcanpro_qi_iap_log1.py` | Qi 芯片 IAP 固件升级（log1.BIN） | 根目录 |
| `zcanpro_qi_iap_log2.py` | Qi 芯片 IAP 固件升级（log2.BIN） | 根目录 |
| `zcanpro_read_app_version.py` | 读取 APP 版本（DID 0xF195/0xF180/0xF193；0xF195 应答=固件编译常量 `SW_VERSION_STR`） | 2.functional test script/ |
| `zcanpro_sn_write.py` | SN 序列号写入（DID 0xF18C） | 2.functional test script/ |
| `zcanpro_qi_read_status.py` | 查询 Qi IAP 升级状态（DID 0x2132） | 2.functional test script/ |
| `zcanpro_qi_read_version.py` | 读取 Qi 芯片版本（DID 0x2133） | 2.functional test script/ |
| `zcanpro_qi_set_power.py` | 设置 Qi 功率（DID 0x210D） | 2.functional test script/ |
| `zcanpro_charge_start.py` | 启动 Qi 充电（DID 0x2101） | 2.functional test script/ |

## 1. pack_image — 镜像打包

版本号硬编码在脚本 `IMAGE_VERSION` 中，无需外部传入；写入镜像头仅作镜像标识/打包校验，运行版本（DID 0xF195）以固件 `SW_VERSION_STR` 编译常量为准。

```powershell
python "python_tools/1.packaging script/pack_image_slotA_1_1_1.py"
```

只编 Slot A（Keil IROM1=`0x08004100`）。不要再打 Slot B 包。

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--bin` | Slot A/B 的 qi_wireless.bin | 裸 APP .bin |
| `--key` | `docs/keys/private.pem` | ECDSA 私钥 |
| `--out` | 自动输出到 `app bin/` | 输出路径 |

## 2. OTA 脚本

下载只在 **APP** 中进行。ZCANPRO 打开 **`zcanpro_ext_ota_auto.py`** 即可：读当前槽，写入对面，镜像若按 A 链接则自动重定位到 B。空片用 `merge_prod_bin.py`。

| 参数 | 值 | 说明 |
|------|-----|------|
| `TRANSFER_BLOCK_DATA` | `128` | 每块字节数 |

| 槽 | 槽基址 | IROM1 Start | IROM1 Size |
|----|--------|-------------|------------|
| Boot | `0x08000000` | `0x08000000` | `0x4000`（16KB） |
| A | `0x08004000` | `0x08004100` | `0xBF00` |
| B | `0x08010000` | `0x08010100` | `0xBF00` |

## 3. Qi IAP 脚本

```powershell
# 在 ZCANPRO 中运行 zcanpro_qi_iap_log1.py 或 zcanpro_qi_iap_log2.py
```

| 参数 | 值 | 说明 |
|------|-----|------|
| `QI_IAP_DATA_LEN` | `22` | 每包最大字节数 |
| `QI_IAP_MAX_RETRIES` | `8` | NRC 0x72 重试次数（启动 + 每包） |
| `QI_IAP_PACKET_DELAY` | `0.2` | 包间延时（秒），给 Qi 芯片写 Flash |
| `QI_IAP_START_DELAY` | `0.5` | `2E 21 30` 成功后再等芯片进入 IAP |
| `STATUS_TIMEOUT` | `120` | 升级超时（秒） |

固件：`python_tools/iap bin/log1.BIN` / `log2.BIN`

log1/log2 除固件名和版本号外完全一致，修改任一脚本后必须同步另一个。

## 4. 功能测试脚本（2.functional test script/）

全部在 ZCANPRO 中运行：

```powershell
python "python_tools/2.functional test script/zcanpro_read_app_version.py"  # 读 0xF195/0xF180/0xF193

python "python_tools/2.functional test script/zcanpro_qi_read_version.py"   # 读 DID 0x2133，Qi 芯片版本
python "python_tools/2.functional test script/zcanpro_qi_set_power.py"      # 写 DID 0x210D，功率 500/1000/1500 mW
python "python_tools/2.functional test script/zcanpro_charge_start.py"      # 写 DID 0x2101，使能充电
```

## 5. 产线工具

### merge_prod_bin.py

最简用法（需先打包好 `app bin/app_slot_a.bin`）：

```powershell
python "python_tools/1.packaging script/merge_prod_bin.py"
```

自定义路径：

```powershell
python "python_tools/1.packaging script/merge_prod_bin.py" --boot <bootloader路径> --app <app镜像路径> --out <输出路径> --hex
```

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--boot` | bootloader.bin | Bootloader 路径 |
| `--app` | app bin/app_slot_a.bin | 已签名 APP |
| `--out` | burn bin/prod_image.bin | 输出路径 |
| `--hex` | — | 同时生成 .hex |

约束：Bootloader ≤ 28KB，APP ≤ 42KB。

### verify_image.py

```powershell
python "python_tools/1.packaging script/verify_image.py" "python_tools/app bin/app_slot_a.bin"
python "python_tools/1.packaging script/verify_image.py" <image> --key docs/keys/public.pem --slot B
```

依赖：OpenSSL CLI（签名验证用）。

### sign_seed.py

```powershell
python "python_tools/1.packaging script/sign_seed.py" <seed_hex_64chars> --key docs/keys/private.pem
```

seed 为32字节（64个十六进制字符）。
