# python_tools — 脚本使用说明

> **Python**: ZCANPRO 要求 **Python 3.8 32 位**
> **入口**: ZCANPRO → 高级功能 → 扩展脚本
> **总线**: Classical CAN 2.0B，250 kbps，29-bit 扩展帧

---

## 脚本总览

| 脚本 | 功能 | 场景 |
|------|------|------|
| `pack_image_slotA_1_1_1.py` | 裸 bin → 签名 .ota.bin（XATO 头 + CRC32 + ECDSA P-256） | 打包 Slot A |
| `pack_image_slotB_1_1_2.py` | 裸 bin → 签名 .ota.bin（XATO 头 + CRC32 + ECDSA P-256） | 打包 Slot B |
| `zcanpro_ext_ota_auto.py` | 自动识别 A/B 槽升级 | OTA |
| `zcanpro_ext_ota_slotA_1_1_1.py` | 指定升级 Slot A | OTA |
| `zcanpro_ext_ota_slotB_1_1_2.py` | 指定升级 Slot B | OTA |
| `zcanpro_qi_iap_log1.py` | Qi 芯片 IAP 固件升级（log1.BIN） | Qi 升级 |
| `zcanpro_qi_iap_log2.py` | Qi 芯片 IAP 固件升级（log2.BIN） | Qi 升级 |
| `zcanpro_qi_read_status.py` | 查询 Qi IAP 升级状态 | 调试 |
| `zcanpro_qi_read_version.py` | 读取 Qi 芯片版本（DID 0x2133） | 调试 |
| `zcanpro_qi_set_power.py` | 设置 Qi 功率（5W/10W/15W） | 调试 |
| `zcanpro_charge_start.py` | 启动 Qi 充电（DID 0x2101） | 调试 |
| `zcanpro_read_app_version.py` | 读取 APP 版本（DID 0xF195/0xF180/0xF193） | 调试 |
| `zcanpro_sn_write.py` | SN 序列号写入（DID 0xF18C） | 产线 |
| `merge_prod_bin.py` | Bootloader + APP 合并为单一产线镜像 | 产线 |
| `verify_image.py` | XATO 镜像完整性 + 签名校验 | 产线 |
| `sign_seed.py` | SecurityAccess seed 签名生成 | 调试 |

## 1. pack_image — 镜像打包

```bash
# Slot A
python python_tools/1.packaging\ script/pack_image_slotA_1_1_1.py \
  --bin qi_wireless_code_slotA/mdk_project/Objects/qi_wireless.bin \
  --version QC_JYF_FW_1.1.1

# Slot B
python python_tools/1.packaging\ script/pack_image_slotB_1_1_2.py \
  --bin qi_wireless_code_slotB/mdk_project/Objects/qi_wireless.bin \
  --version QC_JYF_FW_1.1.2
```

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--bin` | Slot A/B 的 qi_wireless.bin | 裸 APP .bin |
| `--key` | `docs/keys/private.pem` | ECDSA 私钥 |
| `--out` | 自动输出到 `app bin/` | 输出路径 |
| `--version` | `QC_JYF_FW_1.0.0` | 版本字符串 |

## 3. Qi IAP 脚本

```bash
# 在 ZCANPRO 中运行 zcanpro_qi_iap_log1.py 或 zcanpro_qi_iap_log2.py
```

| 参数 | 值 | 说明 |
|------|-----|------|
| `QI_IAP_DATA_LEN` | `22` | 每包最大字节数 |
| `QI_IAP_MAX_RETRIES` | `3` | NRC 0x72 重试次数 |
| `QI_IAP_PACKET_DELAY` | `0.05` | 包间延时（秒） |
| `STATUS_TIMEOUT` | `120` | 升级超时（秒） |

固件：`python_tools/iap bin/log1.BIN` / `log2.BIN`

log1/log2 除固件名和版本号外完全一致，修改任一脚本后必须同步另一个。

## 6. 产线工具

### merge_prod_bin.py

```bash
python python_tools/1.packaging\ script/merge_prod_bin.py \
  --boot qi_wireless_bootloader/mdk_project/Objects/bootloader.bin \
  --app  python_tools/app\ bin/app_slot_a.bin \
  --out  python_tools/burn\ bin/prod_image.bin \
  --hex
```

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--boot` | bootloader.bin | Bootloader 路径 |
| `--app` | app bin/app_slot_a.bin | 已签名 APP |
| `--out` | burn bin/prod_image.bin | 输出路径 |
| `--hex` | — | 同时生成 .hex |

约束：Bootloader ≤ 28KB，APP ≤ 42KB。

### verify_image.py

```bash
python python_tools/verify_image.py python_tools/app\ bin/app_slot_a.bin
python python_tools/verify_image.py <image> --key docs/keys/public.pem
```

### sign_seed.py

```bash
python python_tools/sign_seed.py A1B2C3D4
python python_tools/sign_seed.py A1B2C3D4 --key docs/keys/private.pem
```
