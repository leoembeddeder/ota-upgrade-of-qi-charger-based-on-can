# python_tools — 脚本使用说明

> **Python**: ZCANPRO 要求 **Python 3.8 32 位**
> **入口**: ZCANPRO → 高级功能 → 扩展脚本
> **总线**: Classical CAN 2.0B，250 kbps，29-bit 扩展帧

---

## 脚本总览

| 脚本 | 功能 | 位置 |
|------|------|------|
| `pack_image_slotA_1_1_1.py` | 裸 bin → 签名 .ota.bin（XATO 头 + CRC32 + ECDSA P-256） | 1.packaging script/ |
| `pack_image_slotB_1_1_2.py` | 裸 bin → 签名 .ota.bin（XATO 头 + CRC32 + ECDSA P-256） | 1.packaging script/ |
| `merge_prod_bin.py` | Bootloader + APP 合并为单一产线镜像 | 1.packaging script/ |
| `verify_image.py` | XATO 镜像完整性 + 签名校验 | 1.packaging script/ |
| `zcanpro_ext_ota_auto.py` | 自动识别 A/B 槽升级 | 根目录 |
| `zcanpro_ext_ota_slotA_1_1_1.py` | 指定升级 Slot A | 根目录 |
| `zcanpro_ext_ota_slotB_1_1_2.py` | 指定升级 Slot B | 根目录 |
| `zcanpro_qi_iap_log1.py` | Qi 芯片 IAP 固件升级（log1.BIN） | 根目录 |
| `zcanpro_qi_iap_log2.py` | Qi 芯片 IAP 固件升级（log2.BIN） | 根目录 |
| `sign_seed.py` | SecurityAccess seed 签名生成（32字节） | 根目录 |

## 1. pack_image — 镜像打包

版本号硬编码在脚本 `IMAGE_VERSION` 中，无需外部传入。

```powershell
# Slot A
python "python_tools/1.packaging script/pack_image_slotA_1_1_1.py" --bin qi_wireless_code_slotA/mdk_project/Objects/qi_wireless.bin

# Slot B
python "python_tools/1.packaging script/pack_image_slotB_1_1_2.py" --bin qi_wireless_code_slotB/mdk_project/Objects/qi_wireless.bin
```

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--bin` | Slot A/B 的 qi_wireless.bin | 裸 APP .bin |
| `--key` | `docs/keys/private.pem` | ECDSA 私钥 |
| `--out` | 自动输出到 `app bin/` | 输出路径 |

|------|-----|------|

## 5. 产线工具

### merge_prod_bin.py

最简用法（需先打包好 `app bin/app_slot_a.bin`）：

```powershell
python "python_tools/1.packaging script/merge_prod_bin.py"
```

自定义路径：

```powershell
python "python_tools/1.packaging script/merge_prod_bin.py" --boot <bootloader路径> --app <app镜像路径> --out <输出路径> --hex
```

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--boot` | bootloader.bin | Bootloader 路径 |
| `--app` | app bin/app_slot_a.bin | 已签名 APP |
| `--out` | burn bin/prod_image.bin | 输出路径 |
| `--hex` | — | 同时生成 .hex |

约束：Bootloader ≤ 28KB，APP ≤ 42KB。

### verify_image.py

```powershell
python "python_tools/1.packaging script/verify_image.py" "python_tools/app bin/app_slot_a.bin"
python "python_tools/1.packaging script/verify_image.py" <image> --key docs/keys/public.pem --slot B
```

依赖：OpenSSL CLI（签名验证用）。

### sign_seed.py

```powershell
python python_tools/sign_seed.py <seed_hex_64chars> --key docs/keys/private.pem
```

seed 为32字节（64个十六进制字符）。
