# review_reports — 团队审查/取证产物专用输出

**规则来源**：用户指令（2026-09-20 15:24）——"以后审查文件放在仓库下面，新建一个文件夹专门用于放这些文件，写入规则中"。

**本文件夹收纳**：
- 终审报告（evaluator 对每批代码交付的审查结论，eval_*.md）
- 分析/取证报告（forensics、分支对比、审计类 .md）
- 冒烟测试证据夹（smoke_*/，含测试日志与自测输出）
- 一次性备份件（如 stash 备份 patch）

**输出纪律**：
- 派单任务书中的"报告落盘"路径一律指向本文件夹
- 产物随代码同批提交（或独立 docs 提交）并 push，保持工作树无残留
- 历史 K:\ 盘既有产物原地保留（部分脚本存在硬编码引用），仅不再新增

规则全文见工作区 AGENTS.md「报告输出路径规则」。
